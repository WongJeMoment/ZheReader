# 阅读助手提示词设计

依据 [OpenAI：Rethinking skills and prompts for GPT-6 Astra](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)（2026-09-11），本次审查只调整阅读请求所需的指令与上下文。

- 通用指令只负责语言、材料可信边界、工具权限和输出协议。翻译、解析、解释、检索与带读各自加载目标，不注入其他任务的教学流程。
- 翻译仅生成标题和译文，本机服务补齐前端需要的空字段。翻译不携带旧译文或追问；其他任务仅附带非空上下文。
- 句法解析按原句需要讲解，带读按理解难点展开，不要求每段机械填满整篇论文的分析项目。保留先修知识、引用对应、自测及明确的完成标准。
- JSON Schema、引用逐字校验、来源 URL 检查与工具限制由程序继续执行。文章关于减少重复指令的建议不替代这些产品约束。
- 带读缓存键包含提示词版本；旧结果仍保留，但新请求不把旧版本当作本次生成结果复用。
- 翻译继续使用账号可用的 Luna，其他任务保留所选模型。没有因文章标题自动切换到 Astra。仓库无自定义 SKILL.md 或 AGENTS.md，无需为此次提示词优化新增通用指令文件。

同一空译文输入与固定示例段落测量：通用指令加翻译提示从 887 减为 568 字符，翻译 Schema 从 915 减为 170 字符，通用指令加快速精读提示从 1330 减为 869 字符。字符数不是 token 数，也不代表等比例降低响应时间。

修改任务提示后运行对应的服务协议及桌面交互测试；涉及模型教学行为时，用少量真实短句和论文片段检查译文、先修知识及引用。无需触发全文带读或全量预取。
