# ZheReader

一处安静的阅读空间。用浏览器阅读自己的 PDF 和 EPUB，暖米白与鼠尾草绿的书架设计，面向电脑端阅读。

**在线阅读：[wongjemoment.github.io/ZheReader](https://wongjemoment.github.io/ZheReader/)**

## 使用

1. 打开网站，点击「导入书籍」或拖拽 PDF / EPUB 文件到页面，可批量导入。
2. 点击书籍封面开始阅读，底部按钮或键盘左右键翻页。
3. 顶部可展开目录、添加书签、切换主题和全屏阅读；底部可以调整 EPUB 字号或 PDF 缩放，PDF 支持输入页码跳转及文字选择。
4. 返回书架后点击「继续阅读」，即可恢复阅读位置。也可以按 `/` 搜索书名或作者。
5. 首次使用可点击「探索阅读体验」，阅读本站原创示例《慢读时光》。

默认根据**设备本地时间**自动切换：

- **20:00（含）至次日 07:00（不含）**：静夜深色主题。
- **07:00（含）至 20:00（不含）**：暖纸浅色主题。

页面打开时也会检查时间并自动切换；支持手动固定浅色或深色。EPUB 正文随主题变化，PDF 深色模式会调整页面颜色（包含图片），需要查看原始色彩时可手动选择浅色。

## 语音朗读（电脑端）

打开书籍，点击右上角「听书」：

- **从头朗读全文**：按 PDF 页码或 EPUB 正文顺序逐页、逐章读到末尾，长文本自动分句，不限于当前屏幕。
- **从当前页／章开始**：PDF 从当前页开始，EPUB 从当前章节开头开始，继续读到书末。
- **朗读选中部分**：在 PDF 文字层或 EPUB 正文中用鼠标拖选文字，点击浮出的「朗读选中文字」按钮，也可以在听书面板启动。
- 支持暂停、继续、停止。关闭面板后声音继续播放；返回书架或离开页面会停止。
- 可选声音，调整语速（0.5–2 倍）、音调（0.5–1.5）和音量，并试听。设置保存在当前浏览器；播放中修改设置会重新朗读当前句，暂停时修改会在继续时生效。

音色来自浏览器的 [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)，可用声音取决于操作系统、语音包与浏览器。页面会区分本地声音与在线声音；在线声音可能由浏览器将朗读文字发送给语音服务商。自动模式优先匹配本地中英文声音，缺少本地声音时可能使用在线声音。本站不提供自定义音频上传、声音克隆或付费云端配音。

若无法发声，请检查电脑音量、浏览器声音权限和系统语音包，或换用有可用声音的桌面浏览器。扫描版 PDF 必须先做 OCR 才能朗读，复杂多栏 PDF 按文件内部文字顺序提取。图片中的文字不会自动识别。朗读位置在面板中显示，页面可以独立翻阅。

## GPT 翻译与英语学习（Codex 账号额度）

使用官方 [Codex App Server](https://learn.chatgpt.com/docs/app-server) 与 [ChatGPT 账号登录](https://learn.chatgpt.com/docs/auth)，无需 API Key。额度来自账号的 Codex 使用额度，实际可用性与限制以你的账号为准。电脑需要运行本地连接服务，GitHub Pages 只托管阅读页面。

首次在电脑启动（需要 Node.js 22.13+ 和 Codex CLI）：

```bash
npm install -g @openai/codex
git clone https://github.com/WongJeMoment/ZheReader.git
cd ZheReader
npm ci
npm run start
```

已有项目只需在项目目录运行 `npm run start`。保持终端运行，然后：

1. 打开 **http://127.0.0.1:4318/**，点击「GPT 账号」→「登录 ChatGPT」，在官方页面完成登录；网站会自动刷新登录状态。
2. 也可继续使用在线阅读器：点击「GPT 账号」→「连接本机服务」，在本机弹窗确认连接。若浏览器询问本地网络访问权限，请允许。连接受阻时可直接使用本机阅读器。
3. 在 PDF 文字层或 EPUB 正文中框选文字，稍候显示中文翻译；译文下方提供「句法解析」「解释」「进一步搜索」与朗读原文。
4. 点击解析或解释后，右侧展示句子成分、从句、时态、重点表达与例句；搜索会单独启用联网检索，展示来源链接，并支持输入追问。
5. 账号设置中可搜索与刷新完整模型目录（含默认隐藏条目）、查看额度窗口用量、关闭自动翻译或退出账号。默认隐藏模型单独分组，可能用途有限或不支持阅读任务。

「手动指定模型」允许填写完整模型 ID，供目录尚未列出的模型使用；不保证所有 ChatGPT 模型都可通过 Codex 使用。请求会保留你的模型选择，不支持时直接显示错误，不自动替换为默认模型。刷新列表失败也会保留已选模型。

每次选区最多 8000 字符，追问最多 1500 字符。切换选区会取消旧请求，已发生的模型计算仍可能消耗额度；同一页面会复用相同账号、模型和选区的结果。默认只翻译，解析和搜索由你点击触发。关闭自动翻译后可手动点击「翻译」。扫描 PDF 需要先做 OCR 才能框选文字。

只有选中的文字、其译文及追问会发送给 OpenAI，整本书不会自动上传。模型解释可能有误，搜索页提供来源便于核对。账号凭据由 Codex 管理，保存在本机 `~/.local/share/zhereader/codex`，与已有 Codex 配置分开；阅读页面只持有临时本机配对凭证，服务重启后在线网页需重新配对。连接仅监听 `127.0.0.1`，限制网站来源和访问凭证。可用 `ZHEREADER_PORT` 修改端口（自定义端口请直接打开该本机地址），`ZHEREADER_CODEX_BINARY` 指定 CLI 路径。

本机阅读器和在线阅读器属于不同网站地址，书架数据分别保存；要沿用在线书架，请从在线页面连接本机服务。

## 从坚果云获取 Zotero 论文

适用于已经用坚果云 WebDAV 同步 Zotero「我的文库」附件的电脑。点击书架左侧 **「坚果云论文」**：

1. 保持本机 `npm run start` 服务运行；在线页面先点击「连接本机服务」配对。此功能不需要登录 GPT。
2. 输入坚果云注册邮箱和**第三方应用密码**，目录默认 `https://dav.jianguoyun.com/dav/zotero/`。Zotero 会在 WebDAV 基础目录后追加 `zotero/`，若你使用了自定义父目录，请填写实际附件目录。
3. 点击「连接并获取论文」。可以搜索附件编号、打开子文件夹，或点击 ZIP 条目的「查看 PDF」下载附件包并查看内部文件名。
4. 勾选论文或附件包，点击「导入所选论文」。附件包中的 PDF / EPUB 会逐个导入书架，之后可离线阅读、朗读和划词学习。同内容文件会通过 SHA-256 检查避免重复入库。
5. Zotero 同步了新附件后，点击「刷新论文」重新获取目录并导入需要的文件。也可以输入 8 位 Zotero 附件编号，直接获取目录中尚未显示的附件包。

附件传输是**从坚果云拉取到阅读器**：不会向坚果云上传、修改或删除文件，坚果云本身不负责同步 Zotero 的文献数据。分类关联和标注回传由下方的 Zotero 配套插件实现；阅读进度仍保存在浏览器。云端文件内容更新后重新导入会作为新版本另存，原版本的进度和书签保留。WebDAV 只有附件文件，列表中的 ZIP 名称通常是 Zotero 附件编号，完整的文献数据库仍由 Zotero 管理。普通 PDF / EPUB 文件夹同样可以浏览导入。

应用密码仅用于本机服务向坚果云发起 HTTPS 请求，保存在服务内存中，不写入浏览器存储、项目文件或日志；断开坚果云或重启服务会清除密码。配置时浏览器需将输入的应用密码交给已配对的本机服务，密码不会发送给 OpenAI。文件也由本机服务下载，不经过本站托管服务器。原始附件包临时缓存在内存中，刷新目录、断开或重启后清除。

单个下载／解压文件上限 250 MB，ZIP 条目数与解压大小有额外限制；扫描件仍需 OCR 才能划词。坚果云对 WebDAV 有频率及单次目录条目限制，达到约 750 个响应条目时页面会提示可能不完整，并提供按附件编号获取的入口；不把被截断的列表视为完整文库。应用密码创建步骤及限制见[坚果云官方帮助](https://help.jianguoyun.com/?p=2064)，附件 ZIP / PROP 对应关系见[Zotero 官方说明](https://www.zotero.org/support/kb/files_not_syncing)。

测试使用模拟 WebDAV 响应与生成的 Zotero ZIP / PDF，覆盖目录浏览、中文及旧版编码文件名、文件导入、重复检测、取消、认证失败、来源限制和危险压缩包拦截。真实坚果云连通性与个人附件需填写应用密码后验证。

## 按 Zotero 分类与回传 PDF 标注

本机 Zotero 9 使用配套插件（不需要启用内置 Local API，也不需要 Zotero 云端密钥）：

1. 下载网站「Zotero 分类与标注」中的 [ZheReader Zotero 插件](https://wongjemoment.github.io/ZheReader/downloads/zhereader-zotero.xpi)。源码位于 `zotero-addon/`；运行 `npm run build:addon` 可重新生成安装包。
2. Zotero → 工具 → 插件 → 齿轮菜单 → 从文件安装插件，选择 XPI。当前安装包声明支持 Zotero 9.0.x。
3. 保持 Zotero 和 ZheReader 本地服务运行，在阅读器左侧打开「Zotero 分类与标注」，先配对本机服务，再点击「连接 Zotero」。Zotero 会弹出连接确认框，确认后读取个人文库的分类及 PDF 附件信息。
4. 点击「刷新分类与关联」，既有坚果云论文会通过附件 ZIP 的编号关联；后续导入会使用最近获取的分类目录自动归类。侧栏保留父子分类，选择父分类包含子分类论文；同一篇论文可属于多个分类。Zotero 更新分类后需再刷新一次。
5. 打开 PDF，框选文字后点击「标注选中文字」，选择高亮／下划线及颜色，填写评论后保存。也可通过顶部「论文标注」进入面板，定位、编辑或删除已保存的标注。
6. 点击「同步到 Zotero」，待同步标注会保存为对应 PDF 下的**原生 Zotero 标注**。Zotero 自己的下一次数据同步会将它们同步到其余设备。此操作不覆盖 PDF 附件文件，不占用 GPT 额度。

标注单独保存在 IndexedDB，离线或关闭 Zotero 时仍可保存。稳定的标注编号让重试不会重复创建。已同步标注的删除会先进入待同步队列，点击同步后执行；仅本地的标注可直接移除。移除整本书会清除其本地标注，但不删除已同步到 Zotero 的标注。

同步前会核对个人文库身份、附件编号和原始 PDF 的 SHA-256；本机 Zotero 必须已下载同一份 PDF，版本不同会阻止回传。Zotero 中修改过的同一条标注会触发冲突，保留未同步的本地修改，并提供「采用 Zotero 版本」；该操作明确放弃该条本地修改。当前不自动导入 Zotero 的全部既有标注，也不支持手绘／区域框选标注、EPUB 标注或群组文库关联。

插件只在 Zotero 的本机 HTTP 服务中注册固定接口，配对后接收分类读取和受限制的标注操作；不开放任意 JavaScript、文件路径或数据库语句执行。配对凭证只保存在插件和连接服务内存中，Zotero／服务重启或插件禁用后需重新连接。在 Zotero 禁用插件可撤销连接。

已通过浏览器和插件协议替身测试，并在本机 Zotero 9.0.1 的独立配置和空文库中使用真实 AddonManager 验证 1.0.1 安装成功、插件启动及状态接口返回 200。1.0.1 修复了缺少必填 `update_url` 导致安装器拒绝的问题，构建时生成带 SHA-256 的更新清单。个人文库回传仍需完成连接授权后验证。配套插件依据 [Zotero 插件开发文档](https://www.zotero.org/support/dev/zotero_7_for_developers) 和原生 annotations API 实现；内置接口的版本限制见 [Zotero Local API](https://www.zotero.org/support/dev/web_api/v3/local_api)。

## 数据与支持范围

书籍内容、进度、书签和标注通过 IndexedDB 保存在**当前浏览器、当前网站地址**下，不会自动上传整本书，书架和阅读进度不跨设备同步；主动同步的标注由 Zotero 管理，使用 GPT 功能时会发送选区及追问。请保留原始文件，清除网站数据、更换浏览器或使用隐私模式可能丢失书架。页面字体可从 Google Fonts 加载，加载失败会使用本机字体。

支持常规 PDF 与无 DRM 的 EPUB 2/3。加密 PDF 打开时会询问密码；EPUB 内脚本默认禁用。单个文件导入上限 250 MB，实际容量取决于设备内存与浏览器存储配额。PDF 扫描件可以阅读，但无法选择未经 OCR 的文字。建议使用较新版本的 Chrome、Edge、Firefox 或 Safari。

## 本地开发

需要 Node.js 22.13+（推荐最新 Node.js 22 LTS）。

```bash
npm ci
npm run dev
```

构建和本地预览：

```bash
npm run build
npm run preview
```

浏览器测试：

```bash
npx playwright install chromium
npm test
npm run test:server
```

Playwright 覆盖定时主题、EPUB 导入与目录、书签、进度恢复、PDF 渲染与翻页、重复/无效文件处理和桌面布局。语音测试覆盖整篇跨页/跨章朗读、选区、暂停恢复、停止取消、声音参数保存和失败恢复；通过可控的语音 API 替身验证队列及调用，不代表已试听每种系统音色。测试使用生成的 PDF 与本站原创 EPUB，不含用户书籍。本次测试仅使用桌面视口。

学习功能测试覆盖 PDF / EPUB 选区、自动翻译、侧栏解析、追问检索、未登录提示、停止旧请求与输出转义；使用可控的模型响应替身。服务测试覆盖配对鉴权、来源和 Host 限制、输入校验、Codex 协议及 ChatGPT 登录方式约束。真实模型翻译与联网搜索需要在本机完成账号登录后验证。

`python3 scripts/make_sample.py` 可重新生成示例 EPUB。

## 发布

推送至 `main` 会运行 `.github/workflows/deploy.yml`，构建后发布至 GitHub Pages。仓库 Settings → Pages 的 Source 应设为 **GitHub Actions**。Vite 使用相对资源路径，可部署到 `/ZheReader/` 或其他静态网站目录。

## 技术

Vite、原生 JavaScript、IndexedDB（idb）、[PDF.js](https://mozilla.github.io/pdf.js/)、[epub.js](https://github.com/futurepress/epub.js)、Lucide 图标与 Playwright。PDF worker、CMap、标准字体和 WASM 与网站一同部署，无须第三方 PDF 阅读服务。


## 按标签查找书籍

书架搜索框按标签名称匹配，点击标签按钮可精确筛选，也可查看「未添加标签」的书籍。每本书的「编辑标签」可添加本地标签，用逗号或换行分隔；本地标签保存在当前浏览器。

Zotero 配套插件 1.0.2 起读取论文条目和 PDF 附件上的标签。安装新版后点击「刷新分类与关联」，已导入论文即可按 Zotero 标签查找。Zotero 标签在 Zotero 中编辑，本地标签不会回写 Zotero，刷新关联时会保留。
